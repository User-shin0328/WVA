## 호환성과 판정 보완

완료되지 않은 진단에는 점수·등급을 표시하지 않는다. 점수는 심각 25·높음 15·중간 8·낮음 3점의 건수별 차감과 각 범주 상한 50/30/20/10을 적용한 참고 수치다. A≥90, B≥80, C≥70, D≥60, 나머지 F이며 표준 인증·종합 위험 산정은 아니다.

재진단은 같은 대상 URL·범위 모드·경로 경계·규칙 버전의 완료 보고서만 비교한다. 현재 보고서의 복사본과 범위 정보가 없는 이전 보고서는 제외한다. ‘이번에 미발견’은 조치가 입증됐다는 뜻이 아니다. 변경된 응답이나 수집 범위의 차이도 수동 검토해야 한다.

AI 프롬프트는 관찰 사실·판정 범위·조치 순서·확인 기준을 로컬에서 구성한다. 증거를 지시로 취급하지 않도록 구분하고 외부 서비스로 자동 전송하지 않는다. JavaScript 자격증명 패턴 항목과 TLS 만료 임박 항목에 서로 다른 조치 절차와 한계를 제공한다. TLS 연결은 비동기 방식으로 취소를 전달하며 연결을 정리한다.

브라우저 검증의 비교 패널 검사는 완료 상태 표시 직후 비교 요청이 끝나기 전 판정해 최초 한 번 실패했다. 비교 패널이 실제 표시될 때까지 기다리도록 검사 시점을 수정한 뒤 전체 36건이 통과했다. TLS 검사 최초 작성에서 필수 client 인자를 빠뜨린 테스트 3건도 호출을 수정했고 최종 전체 99건이 통과했다. 이 두 문제로 제품 소스를 바꾸거나 성공 결과를 대체하지 않았다.

디자인 경고는 요청된 위험도 분류의 5색 원형 차트와 모바일 표·보조 라벨의 작은 글씨다. 상세 설명은 14px 이상으로 유지하며 실제 데스크톱·모바일·AI 프롬프트 화면을 직접 확인했다. Impeccable은 진단 중 진행선 모션과 미측정 대시 표현을 보조 경고로 기록했다.

## 한계점과 보완사항

1. 이번 검증은 소유한 로컬 실습 대상과 한 대의 Windows 10 환경이다. 외부 운영 사이트, 별도 Windows 11 장비·백신 환경은 NOT_RUN이다.
2. JavaScript 검사는 발견한 동일 출처 스크립트 최대 5개의 앞 1,000,000자와 한정된 패턴을 사용한다. 공개·테스트 키는 오탐일 수 있고, 실제 키의 유효성은 확인하지 않는다. 난독화·동적 로딩·전체 소스맵은 보장하지 않는다.
3. TLS는 정상 검증 가능한 인증서의 15일 이내 만료를 점검한다. 로컬 루프백은 제외하며 만료·신뢰 오류를 우회하지 않는다. 이번 임박·정상·취소 분기 검사는 모의 연결이며 외부 TLS 실환경 검증은 NOT_RUN이다. 전체 암호군·프로토콜 검사는 없다.
4. 참고 등급은 탐지하지 못한 항목을 반영하지 않는다. 0건이나 A등급은 안전 보증이 아니다. 미발견 비교에는 사람이 응답 증거와 범위를 확인해야 한다.
5. R01~R13 전체는 설계 상태다. 제한적 JS 패턴 기능을 R04 전체 구현으로 표시하지 않는다. 다중 계정 권한 대조와 규칙별 양성·음성·오류 사례를 확장해야 한다.
6. 완료 보고서와 로그는 파일로 남지만 앱 재실행 시 화면 이력을 복원하지 않는다. 민감 증거·로컬 AI 프롬프트를 외부에 붙여넣기 전 사용자가 검토해야 한다.
