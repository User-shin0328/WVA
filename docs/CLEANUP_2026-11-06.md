# 2026-11-06 저장소 정리 기록

WVA 2.7 구현과 검증 결과를 반영하면서 다음 파일을 로컬과 Git 추적 대상에서 삭제했다. GitHub에는 같은 삭제 내역을 커밋하여 반영한다.

| 삭제 파일 | 근거 |
| --- | --- |
| `WVA_README_사용설명서.txt` | README와 현재 사용 설명서로 연결하는 이전 파일명 안내만 있는 파일 |
| `WVA_SYSTEM_DESIGN_SPECIFICATION.md` | `WVA_설계계획서_최종본.md`와 SHA-256이 같은 중복 문서 |
| `reports/WVA_VULNERABILITY_AUDIT_REPORT_DRAFT.md` | 최종 보고서로 대체된 이전 초안 |
| `reports/WVA_취약점분석_결과보고서_초안.md` | 위 영문 파일명 초안과 내용이 같은 이전 초안 |

구현 코드, 실행파일, 의존성, 설치·검증 도구, 최종 보고서와 설계 문서를 보존했다. `mock_target.py`, `START_TESTBED_SITE.bat`, `dashboard/testbed.py`, `tests/lab/`, `tests/benchmarks/`의 테스트 서버와 실습 파일은 삭제하지 않았다. 사용자가 생성한 날짜별 진단 보고서와 로그도 보존했다.

로컬 빌드·테스트 캐시와 임시 파일을 정리하는 삭제 작업은 자동 승인 검토에서 `blocked by policy`로 거부되었다. 우회 삭제하지 않았으며 해당 로컬 파일은 남아 있다. `.gitignore`에 따라 빌드 캐시, 테스트 산출물, 로그, 가상환경은 이번 푸시에 포함되지 않는다.

검증은 `docs/BUILD_INFO.json`, `docs/WORKFLOW_UPGRADE_2.7.md`, `tests/TEST_RESULTS.md`를 따른다. 정리 후 실행파일·소스 연결은 `packaging/build_manifest.py --verify`로 재확인한다.
