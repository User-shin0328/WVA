WVA 2.1 사용 안내 (2026-10-31)

1. WVA.exe를 더블클릭하세요. 기본 주소는 http://127.0.0.1:9030 입니다.
2. 서버 주소를 입력하고 [진단 시작]을 누르면 진행 모션과 완료 차트가 표시됩니다.
3. 발견 항목이나 경로 단계를 누르면 큰 상세 창에서 증거와 조치 절차를 확인합니다.
4. [표면]에서 응답·매개변수·헤더, [로그]에서 기록과 실제 저장 위치를 확인합니다.
5. [저장]에서 정보를 선택하고 JSON, Markdown, CSV 중 형식을 골라 저장합니다.
6. [앱 종료]로 서비스를 종료합니다.

진단 로그: logs/scans/날짜_시간_진단ID.jsonl
앱 오류 로그: logs/WVA.log
자동 보고서: reports/날짜_시간_진단ID.md 및 .json
수동 저장: 브라우저 다운로드 위치

상세 사용 안내: README.md
테스트 순서, 예상 결과, 실제 결과보고서: tests/TEST_GUIDE.md
테스트: .\.venv\Scripts\python.exe -m tests.run_tests
취약 대상: .\.venv\Scripts\python.exe -m tests.lab.target --mode vulnerable --port 8990
방어 대상: .\.venv\Scripts\python.exe -m tests.lab.target --mode hardened --port 8991
